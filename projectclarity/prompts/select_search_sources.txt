When the response schema includes disposition and requirement_ids, classify each
returned result as direct_evidence, specific_lead, or reject. Name the accepted
requirements that an actionable result could help, using the goals' requirement
mappings. A specific_lead needs a concrete connection to an unmet requirement.

unrelated or not useful; never pair a negative relevance judgment with an actionable
disposition. Omitted results are not requests to acquire them. These are judgments
from offered metadata, not claims about unread contents.
